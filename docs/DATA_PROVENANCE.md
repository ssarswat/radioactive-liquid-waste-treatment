# Data provenance

The datasets in `data/processed/` are transcriptions or transformations of
experimental tables in:

**Sushant Sarswat, "Comparative Evaluation of Processing Techniques for
Management of Low Level Radioactive Liquid Wastes", M.Tech dissertation,
Homi Bhabha National Institute, July 2016.**

Important source locations:

- Tables 3.1–3.2: batch material comparison
- Tables 3.4–3.5: heat-treatment / temperature study
- Tables 3.6–3.7: pH study
- Table 3.8: TDS study
- Table 3.9: series column study
- Table 3.10: parallel column study
- Table 3.11: pilot-plant operation
- Table 4.1: fluidisation
- Table 4.2: cement waste product leaching

## Interpretation policy

Values are not silently "corrected" to fit external expectations.
Where PDF table extraction is structurally ambiguous, the repository preserves
the source values and flags the dataset for manual verification.

This repository is an analytical reconstruction of historical experimental work.
It is not a plant operating manual and must not be used as a substitute for
facility procedures, radiological protection controls, regulatory approval,
engineering review, or qualified professional judgement.
